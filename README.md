# ss.lv → Telegram

Бот присылает в Telegram новые объявления с ss.lv по заданным поискам
(дома/дачи и хутора/имения в Лимбажском, Валмиерском и Цесисском регионах).

Работает **бесплатно** на GitHub Actions — ничего платить и никакой карты не нужно.
Скрипт раз в 15 минут читает RSS-ленты поисков, находит новые объявления и
отправляет их в Telegram. Уже отправленные запоминаются в `state.json`,
поэтому повторов не будет.

---

## Что понадобится

1. Аккаунт **Telegram** (у тебя и у отца).
2. Бесплатный аккаунт на **GitHub** (github.com).

Всё. Никаких серверов и оплат.

---

## Шаг 1. Создать Telegram-бота (2 минуты)

1. В Telegram найди **@BotFather** и открой чат.
2. Отправь `/newbot`.
3. Придумай имя (например «SS Māju bots») и username (должен
   заканчиваться на `bot`, например `ss_majas_bot`).
4. BotFather пришлёт **токен** вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его,
   это секрет (никому не показывай, в код не вставляй).

## Шаг 2. Узнать chat_id отца

Бот может писать человеку только после того, как тот сам нажал «Старт».

1. **Отец** открывает бота (по ссылке `https://t.me/<username_бота>`)
   и нажимает **Start**.
2. Чтобы узнать его `chat_id`, отец в Telegram пишет боту **@userinfobot** —
   тот в ответ покажет число `Id:` — это и есть `TELEGRAM_CHAT_ID`.

   > Хочешь получать уведомления и себе для проверки — сделай то же самое
   > со своего аккаунта и на первое время впиши свой id.

## Шаг 3. Залить проект на GitHub

1. На github.com нажми **New repository**.
2. Имя любое (например `ss-telegram-bot`). Тип оставь **Public** —
   для публичного репозитория GitHub Actions работает **безлимитно и бесплатно**.
   (Токен всё равно не попадёт в код — он хранится в Secrets, см. шаг 4.)
3. Загрузи в репозиторий все файлы из этой папки
   (кнопка **Add file → Upload files**, перетащи файлы, включая папку
   `.github`), затем **Commit**.

## Шаг 4. Добавить секреты (токен и chat_id)

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
Добавь два секрета:

| Name | Значение |
|------|----------|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID`   | chat_id отца |

## Шаг 5. Включить и запустить

1. Вкладка **Actions** → если попросит, нажми
   «I understand my workflows, enable them».
2. Слева выбери **ss.lv watcher** → справа **Run workflow** → **Run**.
3. **Первый запуск ничего не отправляет** — он только запоминает все
   текущие объявления (чтобы не завалить отца сотней старых). Дальше, каждые
   15 минут, будут приходить только **новые** объявления.

Готово. Можно проверить: добавь себя в `TELEGRAM_CHAT_ID` временно и подожди,
пока на ss.lv появится что-то новое в этих регионах.

## Как менять настройки

- **Регионы/фильтры** — отредактируй `feeds.txt` (одна ссылка на строку).
  Зайди на ss.lv, выставь нужные фильтры (цена, площадь и т.д.), скопируй URL
  из адресной строки и вставь. Скрипт сам добавит `/rss/`.
  Строку можно временно отключить, поставив `#` в начале.
- **Как часто проверять** — в `.github/workflows/ss-watch.yml` строка
  `cron: "*/15 * * * *"` (`*/15` = каждые 15 минут; `*/30` = каждые 30).
- **Сбросить память** (например, чтобы прислать всё заново) — удали файл
  `state.json` из репозитория.

## Мелочи

- GitHub отключает расписание, если в репозитории **60 дней** вообще нет
  активности. Пока в регионах появляются новые объявления, бот сам делает
  коммиты — расписание живёт. Если вдруг всё замрёт на 2 месяца, GitHub
  пришлёт письмо, и расписание включается обратно одной кнопкой.
- Хочешь слать нескольким людям сразу — проще создать Telegram-**канал**,
  добавить бота администратором и указать в `TELEGRAM_CHAT_ID` id канала
  (напиши мне — подскажу, как получить).
